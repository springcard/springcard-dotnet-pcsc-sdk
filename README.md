# SpringCard .NET PC/SC SDK (archived)

> **This repository is archived. Development continues in [springcard.pcsc.sdk](https://github.com/springcard/springcard.pcsc.sdk).**

This repository contains the previous generation of SpringCard's .NET PC/SC SDK, with sample applications and tools for working with PC/SC smart card readers, contact and contactless smart cards, and NFC/RFID tags.

## Main SDK repository

**[springcard.pcsc.sdk](https://github.com/springcard/springcard.pcsc.sdk) is once again the primary reference for the SpringCard PC/SC SDK.**

Ongoing development is being consolidated there around portable .NET code targeting:

- .NET Framework 4.8
- .NET 6
- .NET 8
- .NET 10

For new projects, updates and contributions, please use that repository. This repository is no longer actively maintained and is retained for reference and access to legacy examples.

## Libraries and documentation

SpringCard's .NET libraries are available as [NuGet packages](https://www.nuget.org/profiles/SpringCard).

Documentation is available at [docs.springcard.com](https://docs.springcard.com/).
